Privacy Policy

Last updated: 18 November 2026

Overview

Beibei Hermes is a private application operated by its owner for personal use only. It accesses only the Google account(s) belonging to the owner.

Data accessed

With the owner's explicit consent via Google OAuth, the application may access Gmail, Google Drive, Google Calendar, Google Sheets, Google Docs and Contacts (read-only) of the owner's own accounts.

Use of data

Data is used solely to provide personal automation features to the owner, such as reading email, syncing files and generating reports. Google user data is not used for advertising or to train generalized AI models.

Sharing and storage

Data is not sold, shared or transferred to any third party. OAuth tokens are stored on a private server controlled by the owner with restricted file permissions.

Revocation and deletion

The owner may revoke access at any time at myaccount.google.com/permissions. Stored tokens can be deleted from the server on request.

Contact

Questions can be raised via the GitHub issue tracker of this repository.
